# мобильная разработка зависит от платформ	 

- ios - закрыта, Swift, objective-C,  X-code, экосистема Apple 
		 - Swift -  современный, простой, много функций. 
		 -  Objective-C - старый, все еще поддерживаемый, но его меньше пользуют 
		 - Используются в Framework X-code для разработки приложений для экосистемы apple 

 - Android - открытый, гибкий, написан изначально на Linux... твою же дивизию... Пишется на Cotlin, Java, Android-studio Framework, экосистема Google	
	- Cotlin - современный, лаконичный, безопасный, создан с учетом недостатков устаревающей Java.
	-  Java - старая, родная, тварь, то еще блин... ее наверное 45% на всех мобилках, слишком уж устоялась.
