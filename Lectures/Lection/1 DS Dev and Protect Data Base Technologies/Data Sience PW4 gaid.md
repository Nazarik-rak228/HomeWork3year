### Введение: зачем нужна визуализация

Визуализация данных — это представление числовых (и иногда категориальных) данных в графической форме. Она позволяет быстро увидеть закономерности, сравнения, тренды, аномалии и структуру, которые в таблице цифр часто незаметны.

В аналитике под визуализацией обычно понимают графики и диаграммы, из которых потом собирают дашборды. Пример из лекции: отчёт по продажам за месяц. Графики переводят язык математики и статистики на язык бизнеса и помогают аналитику увидеть то, что теряется среди бесконечных цифр.

**Ключевой принцип**: для каждого вида данных и задачи существует наиболее подходящий тип графика. Круговая диаграмма отлично показывает доли, но бесполезна для динамики во времени (нет оси времени). Линейный график показывает динамику, но плохо подходит для сравнения многих категорий.

В лекции рассматриваются ключевые типы, которые встречаются чаще всего. Их на самом деле гораздо больше ( treemap, sankey, radar, violin, density, pairplot и т.д.), но базовый набор закрывает 80–90 % повседневных задач.

### 1. Библиотеки: Matplotlib и Seaborn

**Matplotlib** — основная библиотека Python для построения графиков. Почти всё, что рисуется в аналитике на Python, в конечном счёте проходит через неё (pandas и seaborn строят свои диаграммы поверх matplotlib). Она даёт полный контроль: размер фигуры, подписи осей, заголовок, диапазон значений, цвет, толщину линии, положение легенды и т.д.

Работа строится вокруг двух объектов:
- **figure** — вся рабочая область (полотно / окно / картинка целиком).
- **axes** — область внутри figure с осями координат, на которой рисуется график. Одна фигура может содержать несколько таких областей.

Базовый алгоритм:
```python
fig, ax = plt.subplots()          # или plt.subplots(nrows, ncols, figsize=(w, h))
# рисуем на ax
ax.set_title(...), ax.set_xlabel(...), ...
plt.tight_layout()
plt.show()
```

**Seaborn** — надстройка над matplotlib. Делает построение статистических графиков короче и удобнее. Главное отличие: умеет работать напрямую с таблицами pandas. Вместо ручного подсчёта средних по группам достаточно указать столбцы для осей X и Y — seaborn сам посчитает статистику и нарисует результат.

Они не конкурируют, а дополняют друг друга:
- seaborn — быстро и красиво для типовых задач;
- matplotlib — тонкая настройка и нестандартные решения.

#### Расширенная таблица основных методов

| Метод / параметр | Что делает |
|------------------|------------|
| **Создание фигуры** | |
| `plt.subplots(nrows, ncols, figsize=(w, h))` | Создаёт фигуру и области с осями. `nrows`/`ncols` задают сетку. |
| `figsize=(10, 6)` | Размер фигуры в дюймах |
| `plt.tight_layout()` | Подгоняет отступы, чтобы подписи не обрезались |
| `plt.show()` | Выводит график |
| **Заголовки, оси, легенда** | |
| `ax.set_title('текст')` | Заголовок графика |
| `ax.set_xlabel(...)`, `ax.set_ylabel(...)` | Подписи осей |
| `fig.suptitle('текст')` | Общий заголовок всей фигуры |
| `ax.set_xticks([...])`, `ax.set_xticklabels([...])` | Явные положения и подписи делений |
| `ax.legend(title='...')` | Легенда |
| `ax.set_xlim(a, b)`, `ax.set_ylim(a, b)` | Диапазон осей |
| `ax.grid(True)` | Сетка |
| `ax.annotate(...)` | Подпись рядом с точкой |
| `ax.tick_params(...)` | Размер и поворот подписей делений |
| `color`, `linewidth`, `marker`, `linestyle`, `alpha` | Внешний вид |
| **Методы рисования (matplotlib)** | |
| `ax.plot(x, y, marker='o')` | Линейный график |
| `ax.bar(x, height)`, `ax.barh(y, width)` | Вертикальные / горизонтальные столбцы |
| `ax.hist(data, bins=..., edgecolor='white')` | Гистограмма |
| `ax.scatter(x, y, alpha=0.6)` | Диаграмма рассеяния |
| `ax.pie(sizes, labels=..., autopct='%1.1f%%', ...)` | Круговая диаграмма |
| **Функции seaborn** | |
| `sns.set_theme(style='whitegrid')` | Единый стиль всех графиков |
| `sns.barplot(data=df, x=..., y=..., hue=..., palette=...)` | Столбцы средних с доверительными интервалами |
| `sns.boxplot(...)` | Ящик с усами |
| `sns.histplot(..., kde=True)` | Гистограмма + кривая плотности |
| `sns.scatterplot(...)` | Диаграмма рассеяния с раскраской |
| `sns.lineplot(...)` | Линии (в т.ч. несколько рядов) |
| `sns.heatmap(..., annot=True, cmap=...)` | Тепловая карта (корреляции) |

**Полезные факты и best practices**:
- Всегда вызывайте `plt.tight_layout()` или используйте `constrained_layout=True` в `subplots`, иначе подписи часто обрезаются.
- `sns.set_theme(style="whitegrid")` — хороший дефолт для большинства аналитических графиков.
- Цвета лучше задавать осознанно (не полагаться только на дефолтные). Для категорий удобны палитры `Set2`, `tab10`, `deep`.
- При большом количестве точек в scatter всегда используйте `alpha` (0.3–0.7).
- Горизонтальные столбцы (`barh`) почти всегда читаются лучше, когда подписи категорий длинные.

### 2. Линейный график (Line Chart / Line Plot)

**Когда использовать**: динамика во времени, тренды, сезонность, сравнение нескольких рядов по упорядоченной оси X (время, возраст, температура, порядковый номер и т.п.).

**Когда не использовать**: нет естественного порядка на оси X, слишком много рядов (график превращается в «спагетти»), нужны только абсолютные сравнения категорий.

**Универсальный шаблон**:
```python
plt.figure(figsize=(10, 5))
plt.plot(x, y, marker='o', color='darkgreen', linewidth=2)
plt.title('...')
plt.xlabel('...')
plt.ylabel('...')
plt.xticks(...)          # если нужно явно задать подписи
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

**Советы по интерпретации**:
- Смотрите на общий тренд (рост / падение / стабильность).
- Ищите точки перегиба, сезонность, аномальные скачки.
- Если несколько линий — сравнивайте не только уровни, но и скорость изменения.

**Для практической работы (п. 2)**:  
Если в датасете нет упорядоченной переменной (даты, года, возраста и т.п.) — **не стройте** линейный график. Напишите 3–4 предложения: почему он не подходит и какой график лучше использовать вместо него. Дополнительно постройте любой другой график, которого нет в остальных пунктах (например, violinplot, density, pairplot, heatmap корреляций) и опишите его.

### 3. Круговая диаграмма (Pie Chart)

**Когда использовать**: показать состав одного целого (доли). Частей немного (идеально 3–6, максимум 7–8). Значения неотрицательные и в сумме дают 100 %.

**Когда не использовать**:
- Слишком много категорий (сектора сливаются).
- Нужно сравнивать величины между собой (лучше столбцы).
- Есть динамика во времени.
- Нужно сравнивать несколько кругов между собой.

**Шаблон**:
```python
plt.figure(figsize=(8, 6))
wedges, texts, autotexts = plt.pie(
    sizes, labels=labels, autopct='%1.1f%%',
    startangle=90, colors=[...],
    wedgeprops={'edgecolor': 'white', 'linewidth': 1},
    textprops={'color': 'white', 'fontsize': 11}
)
plt.legend(wedges, labels, title='...', loc='center left', bbox_to_anchor=(1, 0.5))
plt.title('...')
plt.tight_layout()
plt.show()
```

**Для практической работы (п. 3)**:  
Если категорий слишком много — **не стройте**. Обоснуйте, почему круг плохо читается, и предложите альтернативу (горизонтальные столбцы или treemap).

### 4. Столбчатая диаграмма (Bar Chart)

**Вертикальная (`bar`)** — удобна при небольшом числе категорий и коротких подписях.  
**Горизонтальная (`barh`)** — лучше при длинных названиях или большом числе категорий.

**Сгруппированная** — когда есть второй категориальный признак (два магазина, два периода и т.д.).

**Когда использовать**: сравнение величин между категориями.  
**Когда не использовать**: динамика во времени (лучше линия), доли одного целого (круг или stacked).

**Универсальные советы**:
- Всегда сортируйте по убыванию значения — сравнение читается намного легче.
- Убирайте лишние подписи осей, если названия категорий уже видны на делениях.
- Для сгруппированных столбцов используйте `hue` в seaborn или явно задавайте позиции в matplotlib.

---

### 5. Диаграмма с накоплением (Stacked Bar)

Горизонтальная stacked barh особенно удобна при длинных названиях.

**Когда использовать**: нужно одновременно увидеть общий итог по категории и его внутреннюю структуру (вклад частей).

**Когда не использовать**:
- Категории не складываются в осмысленный итог.
- Частей слишком много (график становится нечитаемым).
- Главная задача — сравнить отдельные сегменты между полосами (лучше grouped bar).

**Совет**: сортируйте по общему итогу (столбец «всего»).

### 6. Гистограмма (Histogram)

Показывает **форму распределения** одной числовой переменной: центр, разброс, скошенность, количество пиков, выбросы.

**Важные моменты**:
- Число бинов сильно влияет на восприятие. Слишком мало — график сглаживается, слишком много — становится «рваным».
- Подбирайте bins экспериментально (часто начинают с 10–20 или используют правило Стёрджеса / Freedman-Diaconis).
- Столбцы стоят вплотную (в отличие от обычной столбчатой диаграммы).

**Интерпретация**:
- Где основная масса данных?
- Есть ли скошенность (длинный хвост вправо/влево)?
- Есть ли несколько мод (пиков)?
- Есть ли выбросы?

### 7. Диаграмма рассеяния (Scatter Plot)

Показывает связь между **двумя числовыми** переменными: направление (прямая/обратная), силу, нелинейность, кластеры, выбросы.

**Универсальные советы**:
- При большом количестве точек всегда используйте `alpha`.
- Можно добавлять `hue` (раскраску по третьей переменной) и размер маркера.
- Если двух числовых переменных нет — создайте искусственный набор с явной прямой положительной связью (не копируйте пример из лекции).

**Как оценивать связь**:
- Точки образуют чёткую полосу вверх → сильная прямая.
- Полоса вниз → сильная обратная.
- Облако без направления → связи почти нет.
- Есть отдельные точки далеко от основной массы → выбросы.

### 8. Ящик с усами (Box Plot)

Компактная статистическая сводка:
- Линия внутри ящика — **медиана**.
- Ящик — межквартильный размах (IQR = Q3 – Q1, центральные 50 % данных).
- Усы — обычно до 1.5 × IQR от краёв ящика.
- Точки за усами — **выбросы** (по правилу 1.5·IQR).

**Преимущества перед гистограммой**: очень удобно сравнивать несколько групп на одном графике.

**Интерпретация** (обязательно в работе):
- Где медиана?
- Какой IQR (насколько данные «сжаты»)?
- Симметричны ли усы или есть скошенность?
- Есть ли выбросы?

### 9. Сравнение Matplotlib и Seaborn на одной задаче

Классический пример — сравнение средних по группам.

**Matplotlib-путь** (больше кода, полный контроль):
- Вручную считаем `mean()` и `std()` / `sem()`.
- Рисуем `ax.bar` + `yerr`.

**Seaborn-путь** (короче):
- При необходимости делаем `melt` (из широкого формата в длинный).
- Одной строкой `sns.barplot(...)` — сам считает средние и рисует доверительные интервалы.

**Вывод для работы**:  
Seaborn выигрывает по объёму кода и скорости на типовых статистических графиках. Matplotlib даёт больше свободы, когда нужна нестандартная настройка или полный контроль над каждым элементом. В реальной работе почти всегда комбинируют оба подхода.

### Полезные дополнительные факты

- Правило 1.5·IQR для выбросов — это стандарт Tukey. В seaborn boxplot по умолчанию используется именно оно.
- `sns.barplot` по умолчанию рисует 95 % доверительный интервал (можно отключить `errorbar=None`).
- При работе с датами почти всегда полезно сначала сделать `pd.to_datetime` и иногда `df.set_index`.
- Цветовые палитры: для последовательных данных лучше `viridis`, `plasma`, `Blues`; для категорий — качественные палитры.
- Всегда думайте о конечном потребителе графика: аналитик, менеджер или широкая аудитория. От этого зависит степень детализации и «красоты».
