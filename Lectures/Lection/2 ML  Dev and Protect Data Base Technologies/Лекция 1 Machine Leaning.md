История и неожиданные истоки

- **Термин появился в 1959 году.** Его придумал американский ученый Артур Самюэль. Он создал программу для игры в шашки, которая обучалась прямо во время игрового процесса.

- **Первая нейросеть родилась в 1958 году.** Фрэнк Розенблатт создал устройство «Марк-1 Перцептрон». Оно занимало огромную комнату и умело распознавать простые геометрические фигуры. 

- **«Зимы ИИ».** В истории машинного обучения было несколько периодов (в 1970-х и 1980-х годах), когда финансирование исследований полностью прекращалось. Ученые разочаровывались в технологии из-за нехватки вычислительной мощности компьютеров того времени.

# Машинное обучение 
- - технология, с помощью которой компьютер учат понимать информацию с помощью примеров, а не четких правил.

Вместо того, чтобы следовать строго запрограммированным инструкциям, алгоритм учат:
выявлять закономерности, прогнозировать результаты и адаптироваться к изменениям.

# Виды машинного обучения
1. обучение с учителем - в таком случае модель обучается на размеренных данных, где каждому примеру соответствует правильный ответ. (Правильный ответ выбирает разработчик).
	1. примеры задач:
		1. Классификация. 
		2. регрессия.
2. Обучение без учителя - в таком случае алгоритм сам изучает данные и ищет скрытые закономерности. 
	1. Пример: группа похожих объектов или необычная связь между ними.
	2. Пример задач:
		1. Кластеризация.
		2. понижение размерности.
3. комбинированное

# Как работает ML  
1. Собирает данные: на данном этапе нужно собрать информацию, которая будет использоваться для обучения модели,  
2. Разметка данных: проводятся подготовительные работы выделение областей и критериев, которые нужны для обучения машины.  
3. Исследовательский анализ: контрольный этап проверки, при котором специалист проверяет как распределены данные,  
4. Обучение модели: на данном этапе МL специалист выбирает для
решения задачи и обучает несколько подходящих алгоритмов
перспективных моделей. 
5. Тестирование и оценка: по итогу обучения нужно оценить и понять что делать дальше.

# Понятия 
- Категориальный ответ - набор данных с ограниченным числом значений 
- Признак -  X набор исходных данных, который поддается алгоритмам ML
- Метка - обозначается Y , это желаемый результат 
- Целевая переменная - прогнозируемый результат дата-сета 
- Дата-сет - набор исследуемых данных 
	1. Простая запись ( таблица)
		1. Транзакционные данные
		2. Матрица данных.
		3. матрица разряженных данных. 
	2. Граф
		1. Структурированные.
		2. Обычные.
	3. упорядоченные данные
		1. Последовательные.
		2. временные.
		3. Гео-данные.

# Характеристики Дата-сета (DataSet)
- Размерность - кол-во данных.
- Разрежённость - сколько пустых значений.
- Разрешение - диапазон доступных значений.

---
Целевая переменная делиться на **Качественную и количественную**
Первая делится на **бинарную** (два решения) и на **Полиномиальную** (3 и более решений)
Количественная делится на дискретное (целое значение) и непрерывное (Дробь)
